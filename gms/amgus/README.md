# Among Us

This folder contains the Among Us WebGL launcher from [wasmdotrip/AmongUsPort](https://github.com/wasmdotrip/AmongUsPort).

The original build is over 1 GB, so its large binary asset files are loaded directly from the source repository's `main` branch rather than duplicated in Saturn-JS. The launcher and its paths have been adapted for this folder.

Source: https://github.com/wasmdotrip/AmongUsPort
